# 🐾 Conservators Web Application

A web-based application designed for wildlife conservators to monitor and manage animal species data. Built using **HTML, CSS, JavaScript**, and **Express.js**, this system integrates with **Firestore** for storing records and uses the **Animal API** for species information.

---

## 🌿 Features

- 📝 Add new wild animal species to the database  
- 🔄 Update existing animal records  
- 📊 Track percentage population of species  
- 🌐 Fetch species data using Animal API  
- ✅ Input validation for accurate data  
- 📱 Responsive and user-friendly interface

---

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** Express.js (Node.js)
- **Database:** Firestore (Firebase)
- **API Integration:** Animal API
- **Tools:** Git, GitHub, Postman (for API testing)

---

## 📦 Installation

To run the project locally:

# Clone the repository
git clone https://github.com/AdithyaSirigineedi/Conservators-Website.git
cd conservators-webapp

# Install dependencies
npm install

# Start the backend server
node index.js
